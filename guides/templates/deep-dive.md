# Template: deep dive (sample)

An explainer plus a model design: how one could measure and forecast what the question asks about. It is for questions such as "what caused Korea's crashes, and how could the next one be modelled?".

| | |
|---|---|
| Length | 2,000–3,000 English words, plus a technical appendix; Korean about 7,000–10,000 characters |
| Figures | 5–8, including one diagram of the model's structure (a table is fine) |
| Editor gates | question, model, plan, publish |

## Shape

1. Everything in the explainer template, through the content sections.
2. **How one could model it**: the outcome, the drivers and why, the model family and why, and how it would be tested, in plain words with one figure.
3. **What a model can't do**: the limits first, not last.
4. Our read.
5. Technical appendix: variables with their data sources, the structure, the validation plan and alternatives considered. This is `model.json` written for researchers.

Rules: a design, never a forecast. No probabilities of future events. Every driver cites evidence.
