# Template: explainer

One reader question, answered with research and data. This is the live type, and what every skill assumes when a run has no `pipeline`.

| | |
|---|---|
| Length | 1,200–1,800 English words (7–9 minutes); Korean about 4,000–6,000 characters |
| Figures | 3–6, in at least two forms; `key-numbers` stat tiles first |
| Editor gates | question, plan, publish |

## Shape

1. Header: kicker, headline (states the finding), one-sentence dek.
2. Key numbers: three tiles.
3. Key findings: 3–5 sentences, each with a number and a citation.
4. The question: the refined question we answered, what we looked at, and a premise note if one was corrected.
5. 4–6 content sections, each opening with its point, each figure introduced by the paragraph before it.
6. Our read: the insight, the only place for opinion.
7. Terms in this article, references, related reading, the disclaimer (all generated).
