# Voice: Korean edition

The Korean edition is written, not translated: same plan, same facts, same citations, its own sentences (Glacier, Bilingual). The standard is a Korean newspaper's economics explainer: a sentence that reads like English moved into Korean gets rewritten.

## 문체

- 해라체 평서문("~했다", "~이다")으로 쓴다. 공손체는 쓰지 않는다.
- 편집자의 판단은 Insight에서만 쓴다. "우리는 ~로 읽는다" 대신 판단을 그대로 쓴다.
- 본문에서 '우리'를 쓰지 않는다("우리 자료에서", "우리가 비교한"). 출처를 밝히거나("ECB 자료로 따져 보면") 주어를 생략한다.

## 문장: 짧게, 주어 먼저, 서술어는 빨리

- 한 문장에는 사실 하나만 담는다. 숫자가 셋 이상 나오거나 '~지만', '~고', '~며'로 세 번 넘게 이어지면 문장을 나눈다.
- 문장은 평균 45자 안팎으로 쓴다. 60자를 넘으면 나눌 곳을 찾고, 70자는 넘기지 않는다.
- 첫 문장은 '누가 무엇을 했다'로 짧게 쓴다. 맥락과 비교는 다음 문장으로 넘긴다. 신문 기사의 첫 문장처럼 결론이 먼저다.
- 주어는 사람, 기관, 나라로 잡고 능동으로 쓴다. "~에 의해 ~됐다", "~가 이뤄졌다", "~되어지다", "~보여지다"는 쓰지 않는다.
- 꾸미는 말은 짧게 쓰고 꾸밈받는 말 가까이 둔다. 명사 앞 관형절이 20자를 넘으면 문장을 나눈다.
- 문단은 세 문장 안팎, 많아도 네 문장이다. 문단의 첫 문장이 그 문단의 요점이다.

## 번역 투를 쓰지 않는다

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 대부분은 독일과 함께 겪은 것이다 | 대부분 독일 금리도 함께 올랐기 때문이다 |
| 자료는 ~을 보여 준다 | 자료를 보면 ~했다 |
| 아래 그래프는 ~을 비교한다 | 문장을 지우고 그래프 제목에 맡긴다. 꼭 필요하면 "(그래프 2)" |
| 독일 국채에 대한 수요 | 독일 국채를 찾는 수요 |
| 예산 통과를 통해 | 예산이 통과되면서 |
| ~에 있어서 | ~에서 |
| ~로 인해 | ~ 때문에, ~로 |
| ~할 필요가 있다 | ~해야 한다 |
| 가장 큰 ~ 중 하나 | 손꼽히게 큰 |
| 회의를 가졌다 | 회의를 열었다 |
| 대(對)독일 가산금리 | 독일과의 금리 차(가산금리) |
| ~인 것으로 나타났다, ~한 것이다 | ~했다, ~이다 |
| 프랑스의 국채의 금리의 상승 | 프랑스 국채 금리 상승 |
| 그, 그녀 | 이름이나 직함을 다시 쓴다 |
| ~라고 할 수 있다, ~인 것으로 보인다 | 근거가 있으면 단정하고, 없으면 누구의 판단인지 밝힌다 |

## 문장부호

- 쌍점(:)이나 쌍반점(;)으로 두 문장을 잇지 않는다. 두 문장으로 나눈다. 영어식 줄표(—)도 쓰지 않는다.
- 쉼표는 아껴 쓴다. 한 문장에 쉼표가 세 개 이상 필요하면 문장을 나눈다.
- 나열은 가운뎃점(이탈리아·스페인·포르투갈), 연도 범위는 물결표(2010~2012년)로 쓴다.

## 때와 날짜

- 날짜는 연도부터 쓴다(2026년 9월). 같은 문단에서 다시 나오면 "9월"로 줄인다.
- 해가 바뀌는 기간은 두 해를 다 쓴다. "2025년 12월부터 2026년 9월까지"로 쓰고 "12월부터 9월까지"로 쓰지 않는다.
- 기사는 오래 읽힌다. "올해", "지난해"보다 연도를 쓴다.

## 용어와 이름

- 외래어는 국립국어원 표기를 따른다(스프레드, 베이시스포인트, 데이터). 우리말로 쓸 수 있는 영어 낱말은 우리말로 쓴다(펀더멘털은 기초여건, 셀오프는 매도세). 다만 금융 리스크는 한국은행처럼 '리스크'(신용리스크, 유동성리스크, 하방리스크)로 쓰고, 일반적인 위험만 '위험'으로 쓴다. 통화스왑·외환스왑은 한국은행 표기를 따른다(스와프 ×).
- 같은 개념은 한 가지 말로만 쓴다(Glacier 용어집 우선). 처음 나올 때 쉬운 말로 풀거나 용어 표시 `((spread))`를 단다.
- 기관은 처음에 한국어 이름 뒤에 약어를 괄호로 붙이고, 그다음부터 약어만 쓴다. 유럽중앙은행(ECB), 국제통화기금(IMF), 국제결제은행(BIS)이 그 예다.
- 약어는 라틴 문자 그대로 쓴다(bp, GDP, CDS, TPI).
- 논문 제목과 저자 이름은 원문 그대로 둔다(라틴 문자). 기사 속 인물은 한글 표기 뒤에 원어를 붙인다. 케빈 워시(Kevin Warsh)처럼 쓴다.

## 한국은행 용어

경제 용어는 한국은행 통계 보도자료와 경제용어사전의 낱말로 쓴다. 문장 형식은 이 안내를 따르고, 낱말은 한국은행 쪽을 따른다. 근거와 용어 목록은 「한국은행 표현 노트」에 있다(용어표, 구어·번역투 → 한국은행 표현, 숫자·단위·기간).

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 빚, 빚을 내다 | 부채·채무, 차입하다 (외화부채, 대외채무, 신용융자로 매수한 주식) |
| 갚다, 갚을 돈 | 상환하다, 만기가 돌아오는 채무 |
| 재다, 잰 값, 세다 | 측정하다, 산출하다, 집계하다, 평가하다 (시가는 '평가', 통계 수치는 '집계·산출') |
| 빠져나가다, 들어오다 (자금) | 유출되다·순유출, 유입되다·순유입 |
| 들고 있다 (자산) | 보유하다 |
| 번 돈 | 수입, 소득, 수출액 |
| 퍼센트포인트, %포인트 | %p (숫자는 토큰이 '%p'로 렌더링한다) |
| 전년 동기 대비, 전년 동월 대비 | 전년동기대비, 전년동월대비 (붙여 쓴다) |
| 사상 최대, 역대 최고 | (기간) 이후 최대: "2000년 이후 최대", "자료가 있는 1998년 이후 최대" |
| 순국제투자포지션, 대외 포지션 | 순대외금융자산(음수면 순대외금융부채), 대외금융자산·부채 잔액 |
| 포트폴리오 투자 (통계 항목) | 증권투자 |
| 신용등급 강등 | 신용등급 하향 조정 |
| 10억 달러 (단위) | 억 달러, 조 달러 |

- 문장 안에서 숫자를 말로 써야 할 때(사실 토큰이 없는 정책 상수)는 단위도 말로 쓴다("두 퍼센트"). 이때만 '퍼센트포인트'를 쓸 수 있다.
- 한국은행 블로그처럼 쉬운 풀이 한 문장에서는 '빚', '빌리다'를 쓸 수 있다. 정의, 라벨, 표 머리, 지표 이름에서는 쓰지 않는다.

## 숫자

- 숫자는 사실 토큰 `{{F4}}`로만 쓴다. 렌더러가 97bp, 4.44%, +0.2%p, 2,790억 달러, 1조 140억 달러처럼 바꾼다. %포인트는 "%p".
- 숫자는 서술어에 바로 붙인다. "{{F4}}로 2012년 7월 이후 가장 컸다", "{{F5}} 올랐다"처럼 쓰고, '~ 수준이다', '~에 해당하는'을 덧붙이지 않는다.
- 한 문장에 숫자는 둘까지 쓴다.

## 제목

- 결과를 말한다. 40자 이내로 쓰고, 질문형이나 콜론 부제는 쓰지 않는다.
- 신문 제목처럼 서술어를 줄여도 된다("…2012년 이후 최고", "…2011년과는 달라").

## 강조, 인과, 두 판본

- 강조는 이탤릭 대신 굵기로 한다(`*단어*`는 한국어 판에서 weight 600으로 표시된다).
- 인과는 영문판과 같은 규칙을 따른다. 원인을 밝힌 연구가 아니면 "~와 함께 나타났다", "~와 관련이 있다"로 쓴다. 전망 대신 조건과 시나리오를 쓴다.
- 제목, 부제, 핵심 결과는 영문판과 같은 사실을 같은 순서로 말한다. 숫자 집합이 다르면 검사에서 막힌다.

## 고쳐 쓴 예 (france-spread-2026)

**부제**
- 전: 9월 프랑스가 10년 만기로 돈을 빌리며 독일보다 더 낸 금리는 97bp로 2012년 이후 가장 컸지만, 차입 비용 상승의 대부분은 독일과 함께 겪은 것으로, 선진국 전반의 장기 금리 상승과 맞물려 있다.
- 후: 2026년 9월 프랑스와 독일의 국채 금리 차이가 2012년 이후 가장 커졌지만, 프랑스 금리가 오른 것은 대부분 독일 금리도 함께 올랐기 때문이다.

**핵심 결과**
- 전: 차입 비용 상승의 대부분은 독일과 함께 겪은 것이다: 다른 선진국의 장기 금리도 오르는 가운데 프랑스 금리 상승폭 0.88%p 가운데 0.66%p는 독일 금리 자체가 오른 몫이고, …
- 후: 프랑스 금리가 오른 것은 대부분 독일 금리도 함께 올랐기 때문이다. 프랑스 10년물 금리 상승폭 {{F}} 가운데 {{F}}가 독일 금리 상승분이다. 같은 기간 다른 선진국의 장기 금리도 올랐다.

**본문**
- 전: 하지만 우리 자료에서 여름 동안 가산금리가 가장 많이 오른 나라는 프랑스로, 6월부터 9월까지 25bp 올라 이탈리아 상승폭의 2.1배, 벨기에의 2.5배였다.
- 후: 하지만 ECB 자료로 따져 보면 여름에 가산금리가 가장 많이 오른 나라는 프랑스다. 6월부터 9월까지 {{F}} 올랐다. 이탈리아 상승폭의 {{F}}, 벨기에의 {{F}}다.

**Insight**
- 전: 지켜볼 것은 예측이 아닌 조건이다: 다른 유로 국가의 가산금리가 프랑스를 따라 오르는지, 세계적 공포 지표가 높아지는지, 재정적자가 줄어드는지다.
- 후: 앞으로 지켜볼 것은 세 가지다. 다른 유로 국가의 가산금리가 프랑스를 따라 오르는지, 세계 금융시장의 불안 지표가 높아지는지, 프랑스 재정적자가 줄어드는지다.

## 퇴고

- 소리 내어 읽는다. 숨이 차거나 한 번에 뜻이 들어오지 않는 문장은 나눈다.
- 주어와 서술어만 남겨 읽어 본다. 둘이 맞지 않으면 고친다.
- 영문판을 옆에 두고 고치지 않는다. 한국어 판만 읽고 자연스러운지 본다.
